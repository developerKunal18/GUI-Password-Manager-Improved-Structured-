# GUI Password Manager

A simple desktop password manager built using Python.

## Description
This project allows users to store and view passwords securely using a graphical interface.

## Features
- Add account and password
- View stored passwords
- Delete entries
- Encoded password storage

## Technologies Used
- Python
- Tkinter
- base64 module

## How to Run
python app.py

## Purpose
Day 205 focuses on building real-world GUI applications with basic security.
